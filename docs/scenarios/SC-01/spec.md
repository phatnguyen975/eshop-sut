## 2. Preconditions

- The Frontend Web application is running at `http://localhost:5173`.
- The Backend API is running at `http://localhost:3000`.
- The test user's email address (generated by `faker`) does NOT already exist in the system.
- The browser session is unauthenticated (no stored JWT token, no active session).
- At least one product exists in the system (pre-seeded by the SUT).

**Notes:**

- **Step 3** is an independent API-layer verification run in parallel with the UI flow (or immediately after Step 2). It confirms the server enforces FR-01 constraints at the HTTP level, not only in the browser.
- **Step 6** confirms that the backend issues a proper JWT on valid credentials — independent of client-side storage behavior.
- **Loading state (Step 7):** The loading state may be brief; the assertion should use `page.waitForSelector` or an equivalent web-first assertion that catches the state if visible, then confirms the final loaded state.
- **Search safety (Step 9):** The keyword used in the data matrix (Phase 2) includes an XSS payload to verify SEC-04 inline.
- **Empty state (Step 11):** Use a keyword guaranteed to return zero results (e.g., `"xyzzy_nosuchproduct_12345"`).
- All expected responses are derived from `docs/sut/srs.md` FR-01, FR-02, FR-05, FR-21, FR-22, FR-23, FR-24, SEC-04 and `docs/sut/api-specification.md` §1.1, §1.2, §3.1.

### Step 2 — Registration Form Submission [Domain Testing — EP + BVA per field] `[data-driven]`

> **Technique:** Domain Testing — EP (analyzed per field) + BVA (password length)  
> **Implementation annotation:** `[data-driven]` — all variants share the same registration form submission flow. Implement as one `test.each()` block in the registration validation spec.  
> **Data Design Rule:** Valid cases are combined (all fields valid). Invalid cases are isolated (one field invalid, all other fields valid).

#### Equivalence Classes per Field

**Field 1: Họ Tên (Full Name)**

- **Valid:** Non-empty string
- **Invalid:** Empty string (`""`)

**Field 2: Email**

- **Valid:** Valid format (`user@domain.com`), unique in system
- **Invalid:** Invalid format (missing `@`)
- **Invalid:** Invalid format (missing domain part)
- **Invalid:** Valid format but already registered (duplicate)
- **Invalid:** Empty string (`""`)

**Field 3: Mật khẩu (Password)**

- **Valid:** ≥ 8 chars, ≥ 1 uppercase, ≥ 1 lowercase, ≥ 1 digit, ≥ 1 special char (`@$!%*?&`)
- **Invalid:** Missing uppercase letter
- **Invalid:** Missing lowercase letter
- **Invalid:** Missing digit
- **Invalid:** Missing special character
- **Invalid:** Fewer than 8 characters (BVA off-point)
- **Invalid:** Empty string (`""`)

**Field 4: Xác nhận mật khẩu (Confirm Password)**

- **Valid:** Matches password
- **Invalid:** Differs from password
- **Invalid:** Empty string (`""`)
